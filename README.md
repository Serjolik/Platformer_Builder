# Blockout Map Constructor

Локальный конструктор схем игровых локаций на клетчатой сетке.

## Запуск

Дважды щёлкните по файлу `ЗАПУСТИТЬ_КОНСТРУКТОР.cmd`. Откроется адрес `http://localhost:3000`.

Для остановки сервера закройте окно терминала или нажмите в нём `Ctrl+C`.

## Управление

- Перетащите шаблон из палетки слева на карту.
- Колесо мыши — масштаб.
- Средняя кнопка мыши или инструмент «Рука» — перемещение карты.
- Инструменты «Линия» и «Стрелка» рисуют между узлами сетки.
- `Delete` — удалить выбранное; `Ctrl+Z` / `Ctrl+Y` — отмена / повтор.
- Проект автоматически сохраняется в браузере. Кнопки «Экспорт JSON» и «Импорт» позволяют переносить карту как файл.

## Разработка

Требуется Node.js 22 или новее.

```text
npm install
npm run dev
```
